# XY Pad

XY Pad, by [Tech Audio](https://techaud.io/), is a software pad controller for
plugin parameters in [REAPER](https://www.reaper.fm/). Map FX parameters to the
X and Y axes, then drag across the pad to control them all at once.

## Installation

XY Pad is distributed via [ReaPack](https://reapack.com/):

1. In REAPER, go to `Extensions` > `ReaPack` > `Manage repositories...` and add
   the Tech Audio repository:
   `https://github.com/TeamAudio/reascripts/raw/main/index.xml`
2. Go to `Extensions` > `ReaPack` > `Browse packages...`, search for `XY Pad`,
   and install it.
3. Run `TA_XY Pad` from the Actions list.

Requires [ReaImGui](https://github.com/cfillion/reaimgui) (also available via
ReaPack).
